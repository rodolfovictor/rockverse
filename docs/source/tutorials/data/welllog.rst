======================
Working with well logs
======================

Well log data represents scalar information measured along a wellbore, 
typically indexed by depth or time. Since well logs are essentially scalar fields 
defined over one or more coordinates, we can easily derive a specialized class for 
well logs from the general ScalarField class.
